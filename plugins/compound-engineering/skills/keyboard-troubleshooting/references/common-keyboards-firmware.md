# Common Bluetooth Keyboards and Firmware Toggles

Quick reference for popular Bluetooth keyboards and their Mac/Windows mode toggles and firmware features.

## Budget/Consumer Keyboards

### Meetion KB-BT2
**Mac/Windows Toggle:** Fn + R
**Indicator:** Blue subtext on special Fn keys
**Notes:**
- Commonly available, budget-friendly option
- Each Fn key has blue printed combination
- When in Windows mode, modifier keys appear swapped on Mac
- Toggle is immediate, no restart needed

**Example behavior in Windows mode on Mac:**
- Cmd key produces Option behavior
- Option key produces Cmd behavior
- Control key may also be affected

### Logitech MX Keys / MX Keys Mini
**Mac/Windows Toggle:** Fn + Delete (press together)
**Indicator:** Automatic detection based on paired device
**Notes:**
- Smart keyboard that often auto-detects Mac vs Windows
- Can pair with multiple devices simultaneously
- May need manual toggle if auto-detection fails
- Uses Logitech Options software for advanced configuration

### Apple Magic Keyboard
**Mac/Windows Toggle:** Not applicable
**Notes:**
- Native Mac keyboard, no firmware mode toggle
- Always expects Mac key layout
- Any key swapping on this keyboard indicates software issue

### Keychron K Series
**Mac/Windows Toggle:** Fn + X (press together)
**Indicator:** LED indicator or manual documentation
**Notes:**
- Popular mechanical keyboard option
- Supports both Bluetooth and USB
- Some models have DIP switches for additional configuration
- Check included documentation for specific model

### Asus ROG Ally Keyboard
**Mac/Windows Toggle:** Fn + P (for profile switching)
**Indicator:** LED indicator shows active profile
**Notes:**
- Gaming-oriented keyboard
- Has Gaming Mode toggle (usually Fn+G or dedicated key)
- Multiple profiles can be programmed
- Profile 1 typically Mac, Profile 2 typically Windows

## When Model Not Listed

**For keyboards not listed above:**

1. **Check the physical keyboard:**
   - Look for printed Fn key combinations in blue or other highlight color
   - Check underside for DIP switches or mode indicators
   - Look for printed mode labels (Mac/Windows, Device 1/2/3)

2. **Search manufacturer resources:**
   - Product manual (usually PDF on manufacturer website)
   - Support documentation or FAQ
   - YouTube unboxing/review videos often demonstrate mode toggles

3. **Common toggle patterns to try:**
   - Fn + R (most common for budget keyboards)
   - Fn + W (Windows mode)
   - Fn + M (Mac mode)
   - Fn + A (Alt/Windows)
   - Fn + Delete (less common but documented)
   - Long-press power button (some reset to defaults)

4. **Verification:**
   - After attempting toggle, test one command key combination (e.g., Cmd+C)
   - If behavior changes, toggle was successful
   - If unchanged, try different combination

## Important Notes

1. **Mode toggle is usually immediate** - No restart needed, keyboard responds right away
2. **Different pairing modes can coexist** - Some keyboards support simultaneous multi-device pairing with different modes for each device
3. **Check printed legends** - Blue or highlighted text on keyboard usually indicates special Fn combinations
4. **Manual is authoritative** - Always trust the official documentation for your specific model and firmware version
5. **Firmware updates matter** - Some keyboards receive firmware updates that change toggle behavior or add new features
6. **USB vs Bluetooth may differ** - The same keyboard may behave differently depending on connection type

## How to Find Your Keyboard Model

If unsure about your keyboard model:

1. **Check physical keyboard** for manufacturer name and model number
2. **Check Bluetooth settings** (Mac: System Settings → Bluetooth → [Keyboard Name])
3. **Search on Amazon or retailer** for exact model name
4. **Check receipt or packaging** if still available
5. **Contact manufacturer support** with approximate purchase date and features

Once you have the model number, search manufacturer website for:
- User manual (PDF)
- Support documentation
- Firmware update history
- Known issues and solutions
